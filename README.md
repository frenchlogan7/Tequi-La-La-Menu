# Tequi-La-La-Menu

Menu for Tequi-La-La bar. Open `index.html` in a browser to view the full menu.

## Sections

- **Food** – snacks and bites ranging from $8 to $40
- **Drinks** – non-alcoholic and alcoholic beverages ranging from $8 to $156
- **Specials** – bundles and signature smoothies ranging from $100 to $3,000
